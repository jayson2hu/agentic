# Codex 任务：实现 CodePick · L2 判断与智能体（独立开发，最后联调）

## 角色
你是资深 Python/LangGraph 工程师，独立负责实现 CodePick 平台的 **L2「判断与智能体」**：在内容知识上做垂直评分、翻译、推荐、伴读。这是平台的护城河层。

## 背景（重要）
CodePick 是分层数据平台：**L0 数据底座 → L1 数据加工 → L2 判断与智能体 → L3 应用与分发**。
4 层由不同会话**并行开发，最后统一联调**。你只负责 L2。开发期你用 **stub 假装 L1**；联调时换成真实 L1。因此你必须**严格遵守输入/输出契约**。

## 输入材料（本文件夹 4 份 HTML，先全部读完再动手）
- `L2-判断与智能体-产品文档.html` —— 目标、按垂直 lens、产物契约、边界
- `L2-判断与智能体-架构设计.html` —— 垂直 lens 抽象、评分/翻译/推荐/伴读图、数据模型
- `L2-开发Plan-详尽版.html` —— EPIC/Feature 拆解 + 每项「验收标准」+「自测」（实现依据）
- `L2-实施手册-交付包.html` —— 脚手架、接口契约、图规格、配置、冒烟自检

## 任务
按《开发Plan》的 EPIC **E0→E9**、Feature 顺序实现，**逐个用其「验收标准」+「自测」收口**；
按《实施手册》的脚手架、接口契约、图规格、配置落地。

## 硬约束（不可违背）
1. **独立开发**：取 base_analysis 只经 `AnalysisProvider`，注入 `StubAnalysisProvider` + fixtures；LLM 用 `FakeLLM`。**不依赖真 L1、不真调模型。**
2. **标准走配置**：判断标准走 `verticals` 的 lens 配置（rubric / 标签体系 / source_filter），**不要硬编码进代码**。先做 `ai-coding` 一个 lens。
3. **冻结契约**（上层 L3 唯一依赖，不可改）：
   - 输入：事件 `content.analyzed` 触发；`AnalysisProvider.get(id) -> BaseAnalysis`
   - 输出：`content_vertical_scores`（content×vertical：relevance + 六维分 + 垂直标签）+ `content_translations`（中英）+ 事件 `content.completed {content_id}`
   - 请求时接口：`recommend(user_id, vertical, limit)`、`companion(content_id, question)`（SSE）
   - 表归属：L2 **只写** `verticals / content_vertical_scores / content_translations / review_queue`，**只读** `content_items / content_base_analysis`
   - 状态推进：`WAIT_SCORE → WAIT_REVIEW → COMPLETED` / `CANCELLED`
4. **评分模式**：用"评分 → 反思(扮演领域评审专家) → 优化"三步，提升稳定性。
5. **可测性**：所有 LLM 节点能用 `FakeLLM` 确定性测试，CI **不真调模型**。
6. **依赖方向**：`judgment_graph` 不得 import L3，对 L1 仅经 `AnalysisProvider` 接口。
7. **技术栈**：Python 3.12 / LangGraph / PostgreSQL + pgvector / SQLAlchemy + Alembic / Arq。

## 交付标准（DoD）
- 每个 Feature 通过其「自测」；每个 Sprint 末 `make l2-smoke` 输出 `L2 PIPELINE: PASS`。
- 覆盖率 ≥ 80%，ruff / mypy / CI 全绿。
- 满足《实施手册》第 7 节 L2 DoD 全部条目（含：stub 独立跑通、六维分合法、翻译一致、精审闭环、推荐/伴读可用）。
- 产出：可运行代码 + 测试（FakeLLM + fixtures）+ Alembic 迁移 + ai-coding lens seed + README。

## 工作方式
- 每完成一个 Sprint 提交一次，附：已实现 Feature、自测结果、覆盖率、遗留项。
- **联调预留**：`StubAnalysisProvider` 与真实 L1 可一键切换；冻结契约保持稳定。
- 契约歧义**先停下提问**，不擅改冻结契约。
