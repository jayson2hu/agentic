L2 判断与智能体 — 详尽开发计划

L2 在 L1 的"内容知识"上做判断与智能处理：垂直评分、翻译、推荐、伴读。这是护城河层。拆成 10 EPIC / ~28 小功能，每个含验收与自测；可对 L1 stub 独立开发。核心：引擎通用、标准按垂直 lens 配置。

范围：评分/翻译/推荐/伴读 EPIC：10小功能：~28 预估：~17 人日 栈：Python · LangGraph · PG/pgvector

i说明与范围

仅覆盖 L2。消费 L1 的 content.analyzed + base_analysis，产出垂直评分/翻译/推荐/伴读。MUST=MVP，SHOULD=V1。

⇄并行开发与契约

⬇ 输入契约（来自 L1，可 stub）

  • 事件 content.analyzed {content_id}
  • AnalysisProvider.get(id) -> BaseAnalysis（含 summary/key_points/entities/embedding）
  • standalone：StubAnalysisProvider + fixtures，无需真 L1

⬆ 输出契约（给 L3）

  • content_vertical_scores（content×vertical）
  • content_translations（中英）
  • 状态 WAIT_SCORE→WAIT_REVIEW→COMPLETED + 事件 content.completed
  • 请求时：recommend() / companion()
统一接缝：L2 拥有 verticals/content_vertical_scores/content_translations/review_queue 表，只读 content_items/content_base_analysis。集成时把 StubAnalysisProvider 换成真 L1 即可。

▦里程碑（4 Sprint）

Sprint目标EPIC预估
L2-S1 骨架+lens图底座 + L1 stub + 垂直 lens 加载E0·E1·E2~4.5d
L2-S2 评分+翻译评分图（含反思优化）+ 翻译图E3·E4~5d
L2-S3 精审+产物精审闭环 + 持久化 + 事件E5·E8~3d
L2-S4 推荐+伴读+成本推荐重排 + 伴读 + 重放E6·E7·E9~4.5d

▤数据库 DDL（L2 拥有）

CREATE TABLE verticals(
  code TEXT PRIMARY KEY, name TEXT, enabled BOOL DEFAULT true,
  source_filter JSONB DEFAULT '{}', rubric_prompt TEXT, rubric_version TEXT,
  tag_taxonomy JSONB DEFAULT '{}', brief_template TEXT, model_profile JSONB DEFAULT '{}');

CREATE TABLE content_vertical_scores(
  content_id BIGINT REFERENCES content_items(id), vertical_code TEXT REFERENCES verticals(code),
  relevance INT, dim_scores JSONB -- {topic,content,depth,practical,novelty,expression},
  vertical_tags JSONB DEFAULT '[]', quality_score INT,
  reviewed BOOL DEFAULT false, review_note TEXT, rubric_version TEXT, model TEXT,
  PRIMARY KEY(content_id, vertical_code));

CREATE TABLE content_translations(
  content_id BIGINT REFERENCES content_items(id), lang TEXT,
  fields JSONB, model TEXT, PRIMARY KEY(content_id, lang));

CREATE TABLE review_queue(
  id BIGSERIAL PRIMARY KEY, content_id BIGINT, vertical_code TEXT,
  reason TEXT, status TEXT DEFAULT 'pending', reviewer TEXT, decided_at TIMESTAMPTZ);

CREATE TABLE user_interest_vectors(  -- 推荐用，L3 触发更新
  user_id BIGINT PRIMARY KEY, vector vector(1536), updated_at TIMESTAMPTZ);

★L2 总验收（DoD）

  • 用 L1 stub + FakeLLM 独立端到端跑通并验收
  • 评分：六维分合法、与精审一致性达标、含反思优化
  • 翻译：中英完整自然、术语一致
  • 精审闭环：低置信入队、裁决推进状态、可校准
  • 推荐：两路召回 + 重排合理；伴读基于内容流式
  • 产物契约：vertical_scores/translations 完整；content.completed 不丢不重；状态正确
  • 成本可控、可重评；覆盖率达标、CI 全绿（不真调模型）
达成即：L2 可独立交付，向 L3 稳定供给"带判断的内容"。集成时换 AnalysisProvider 为真 L1。
