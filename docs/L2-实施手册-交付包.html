2接口契约（关键签名）

# 输入（解耦 L1）
class AnalysisProvider(Protocol):
    def get(self, content_id: int) -> BaseAnalysis: ...   # summary/key_points/entities/embedding
class StubAnalysisProvider: ...   # 读 fixtures

# lens
class Lens: code; rubric_prompt; rubric_version; tag_taxonomy; source_filter; model_profile
def load_lens(vertical_code: str) -> Lens

# 评分图状态与产物
class VerticalScore(BaseModel):
    content_id: int; vertical_code: str; relevance: int
    dim_scores: dict   # topic/content/depth/practical/novelty/expression
    vertical_tags: list[str]; quality_score: int; rubric_version: str

# 输出契约（给 L3，冻结）
def persist_score(s: VerticalScore) -> None              # upsert (content,vertical)
def persist_translation(content_id, lang, fields) -> None
def emit_completed(session, content_id) -> None           # outbox: content.completed
# 请求时
def recommend(user_id: int, vertical: str, limit: int) -> list[ContentRef]
def companion(content_id: int, question: str) -> Iterator[str]   # SSE
冻结点：VerticalScore / content_translations / content.completed 是 L3 唯一依赖。定死即可并行 + 统一。

3图规格

scoring_graph(vertical): relevance_gate→score_6dim(注入rubric)→vertical_tag→reflect_check→refine→persist→(review_queue?)→emit
translate_graph(target_lang): identify_terms→translate→check→refine→persist
companion_graph: load(base+text)→retrieve→answer(SSE)
档位: score/translate=standard; relevance_gate=cheap
缓存: (content_id, vertical, rubric_version)
